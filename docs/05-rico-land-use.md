# 5. RICO Land Use

## RICO/F model

ConsoleCity uses five broad economic land-use classes:

-   **Residential**
-   **Industrial**
-   **Commercial**
-   **Office**
-   **Farming**

The model can be referred to as **RICO/F** where the farming category
needs to be explicit.

## Residential

Provides housing.

Examples:

-   detached house;
-   townhouse;
-   apartment;
-   high-density residential.

Outputs:

-   residents;
-   labour supply;
-   consumer demand;
-   utility demand.

Consumes:

-   food;
-   water;
-   electricity;
-   services;
-   transport.

## Industrial

Produces physical goods or processes resources.

Examples:

-   factory;
-   processing plant;
-   warehouse;
-   heavy industry;
-   recycling facility.

Consumes:

-   workers;
-   raw materials;
-   electricity;
-   water;
-   logistics capacity.

Outputs:

-   goods;
-   waste;
-   employment;
-   freight traffic;
-   tax/economic activity.

## Commercial

Provides goods and consumer services.

Examples:

-   supermarket;
-   restaurant;
-   retail store;
-   petrol station;
-   entertainment venue.

Consumes:

-   workers;
-   electricity;
-   water;
-   inventory;
-   transport access.

Outputs:

-   consumer services;
-   sales;
-   employment;
-   tax/economic activity.

## Office

Provides professional/administrative employment.

Examples:

-   office building;
-   corporate headquarters;
-   professional services;
-   technology business.

Consumes:

-   workers;
-   electricity;
-   telecom;
-   commercial services;
-   transport.

Outputs:

-   services;
-   employment;
-   economic activity.

## Farming

Produces biological/raw food resources.

Examples:

-   crop farm;
-   livestock farm;
-   orchard;
-   greenhouse.

Consumes:

-   land;
-   water;
-   equipment;
-   workers;
-   energy.

Outputs:

-   food;
-   raw materials;
-   agricultural waste.

## Land-use interaction

Land use should create demand for other systems.

For example:

``` text
Residential growth
→ population growth
→ worker supply
→ consumer demand
→ need for roads
→ utility demand
→ schools/services
→ commercial growth
→ more employment
→ further population attraction
```

This feedback loop is central to city growth.
