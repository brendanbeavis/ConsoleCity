# 6. Buildings and Organisations

## Building

A building is a physical structure occupying one or more cells.

Core properties:

-   type;
-   footprint;
-   capacity;
-   construction cost;
-   construction duration;
-   maintenance;
-   utility requirements;
-   jobs;
-   occupants;
-   production/consumption;
-   condition;
-   owner.

## Organisation

An organisation is an economic or civic actor operating one or more
facilities.

Examples:

-   supermarket chain;
-   manufacturing company;
-   farm;
-   police department;
-   city government;
-   utility operator.

An organisation can own buildings and employ people.

## Business lifecycle

``` text
Founded
→ Operating
→ Expanding / Stable / Contracting
→ Insolvent
→ Closed
```

## Business decisions

Businesses can:

-   hire;
-   fire;
-   change wages;
-   change production;
-   order inventory;
-   adjust prices;
-   expand;
-   relocate;
-   close.

The first implementation can use simple rules instead of full corporate
simulation.

## Capacity

Buildings expose capacities such as:

-   residents;
-   jobs;
-   customers;
-   service throughput;
-   storage;
-   production.

Capacity constraints create meaningful interactions.

## Construction

Construction consumes:

-   money;
-   materials;
-   labour;
-   time.

Construction sites should temporarily consume transport and labour
capacity.

## Condition and maintenance

Buildings degrade gradually.

Low condition can cause:

-   lower productivity;
-   lower desirability;
-   higher failure probability;
-   service disruption.

Maintenance spending reduces degradation.
