# 9. Infrastructure

## Infrastructure principle

Infrastructure is represented as networks and facilities with capacity.

## Electricity

Objects:

-   generation;
-   substations;
-   distribution lines;
-   storage.

Properties:

-   generation capacity;
-   demand;
-   reserve margin;
-   reliability.

Shortfall effects:

-   industrial production falls;
-   businesses close temporarily;
-   households experience outages;
-   service quality falls.

## Water

Objects:

-   reservoirs;
-   treatment plants;
-   pumping stations;
-   pipes.

Demand comes from:

-   households;
-   farms;
-   businesses;
-   industry;
-   services.

## Sewage

Wastewater is generated by population and businesses.

Network capacity can be overloaded.

## Waste

Waste sources:

-   households;
-   businesses;
-   industry;
-   construction;
-   agriculture.

Facilities:

-   collection;
-   transfer;
-   landfill;
-   recycling;
-   waste-to-energy.

## Telecommunications

Telecom capacity affects:

-   offices;
-   businesses;
-   digital services;
-   advanced technology;
-   emergency communications.

## Fuel

Fuel infrastructure supports:

-   vehicles;
-   industry;
-   power generation;
-   aviation;
-   logistics.

## Infrastructure dependencies

Infrastructure can depend on other infrastructure.

Example:

``` text
Power outage
→ water pumps fail
→ water pressure falls
→ households/services affected
→ economic activity falls
```

## Network model

Each utility should use a graph:

``` text
Node = facility / connection point
Edge = pipe / cable / network link
Capacity = maximum flow
Flow = current demand
```

The first implementation can use simplified proportional allocation
instead of full hydraulic/electrical simulation.
