# 11. Farms and Food

## Agriculture

Farms convert land, labour, water and inputs into food/raw agricultural
resources.

## Farm types

-   crop farm;
-   livestock farm;
-   orchard;
-   greenhouse;
-   mixed farm.

## Inputs

-   land;
-   water;
-   workers;
-   equipment;
-   seed/feed;
-   fertiliser;
-   energy.

## Outputs

-   grain;
-   vegetables;
-   fruit;
-   livestock;
-   dairy;
-   meat;
-   other food resources.

## Processing

Food processing converts agricultural resources into consumer products.

Example:

``` text
Farm → processor → warehouse → supermarket → household
```

## Seasonality

Later simulation versions can model:

-   planting;
-   growth;
-   harvest;
-   seasonal demand;
-   weather effects.

## Food shortages

If production/logistics cannot satisfy demand:

-   prices increase;
-   inventories fall;
-   household satisfaction falls;
-   migration pressure can rise.

## Agriculture and city growth

Cities consume agricultural output but urban expansion can reduce nearby
farmland.

This creates a strategic land-use conflict.
